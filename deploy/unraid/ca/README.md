# Broadwave for Unraid

The Unraid Community Applications template for [Broadwave](https://github.com/wolfebase/broadwave): live TV and DVR for an antenna.

Install it from the **Apps** tab: search for Broadwave. The [install guide](https://github.com/wolfebase/broadwave/blob/main/docs/guide/install.md#unraid) explains each setting.

Report problems at https://github.com/wolfebase/broadwave/issues.

This repository is a copy. The template is maintained in `deploy/unraid/ca/` of the Broadwave repository; change it there and copy it here.
