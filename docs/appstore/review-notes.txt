Broadwave is the Apple TV, iPhone, and iPad player for a free, open-source server (https://github.com/wolfebase/broadwave) that people run at home with their own antenna and a tuner such as an HDHomeRun. The app hosts and provides no content. It plays the free over-the-air broadcasts the user's tuner receives, the way a television does. There are no accounts, no user-generated content, and no paid features.

Audience: households that receive local broadcast television. Listed in the United States and Canada. It works the same in both. Channels depend on the local broadcasters the antenna can receive (ATSC).

Setup: the user runs the server on their network (Docker, Unraid, or a Mac). The app finds it with Bonjour or a typed address. No app credentials and no sample files. An optional Schedules Direct account or XMLTV link is entered on the server only if the user wants a longer guide.

To try it: on a Mac with Docker, run `docker run -p 8477:8477 ghcr.io/wolfebase/broadwave:latest`, open http://localhost:8477, add a playlist (Settings > Sources > M3U URL), then open the app and enter the Mac's address. The attached videos show Home, the guide, live playback, and two channels side by side. Those demo channels are Blender Foundation open movies (CC BY), which is also what the screenshots show. We can provide a reachable test server on request.

The apps talk only to the user's server. That server may contact the tuner on the local network; a guide the user enables (SiliconDust, Schedules Direct, or an XMLTV address); public ESPN scoreboards (NFL, college football, NBA, WNBA, college basketball, MLB, NHL, MLS, NWSL, Premier League, and F1 and NASCAR schedules); and playlists the user adds. There are no authentication, payment, analytics, or AI services. Wolfe Up LLC receives none of this data.

The app does not supply broadcast television or team logos. Screenshots and the attached videos are CC BY open movies, not broadcast TV. Scores only label a game the user is already receiving.

Permissions: Local Network finds the server with Bonjour (_broadwave._tcp). NSAllowsArbitraryLoads is set because a home server is reached by a LAN or VPN address over plain HTTP.
