# Broadwave

Broadwave is live TV and DVR for an antenna. You run the server at home. It talks to a network tuner, fills the guide, records the broadcast, and plays it on a browser, an iPhone, an iPad, an Apple TV, and a Cast television.

One tune of a channel feeds every screen and every recording. Screens in the house play the same moment.
