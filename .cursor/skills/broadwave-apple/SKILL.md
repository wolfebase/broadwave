# Broadwave Apple apps

## Layout

- `apple/project.yml` is the source of truth (XcodeGen). `Broadwave.xcodeproj` is generated and git-ignored: run `cd apple && xcodegen generate` after adding files/targets.
- Targets: `Broadwave` (iOS/iPadOS), `BroadwaveTV` (tvOS). Shared screens in `apple/App/Shared` with `#if os(tvOS)` / `#if os(iOS)` branches. Minimum iOS/tvOS 26.1 (Liquid Glass + `tabViewBottomAccessory(isEnabled:)`).
- `Packages/BroadwaveKit`: models (mirror `api/openapi.yaml` by hand; keep in sync), `APIClient`, `Discovery` (NWBrowser `_broadwave._tcp`, resolves via NWConnection), `EventSocket` (clock sync + rooms), `SyncEngine` (AVPlayer), `AppStore` (@Observable app state), `Guide` (category rules identical to web `lib/guide.ts`), `Capabilities`.
- `Packages/BroadwaveUI`: `Theme+Tokens.swift` (GENERATED by `node design/build.mjs`; never edit), components (ChannelBadge, LiveDot, AiringProgress, NowCard, OnNowRow).

## Build and test

```bash
make apple-test   # BroadwaveKit Swift Testing (fixtures are real server JSON)
make apple        # xcodegen + iOS + tvOS simulator builds, CODE_SIGNING_ALLOWED=NO
```

Swift 6 strict concurrency is on. Xcode here is 26.6 with iOS 26.5, iOS 27.0 runtime, and tvOS 26.5 installed. Use `#available(iOS 27, *)` for iOS 27 APIs.

## Run in simulators against the dev server

```bash
# iPhone 17 Pro: BE69F376-A952-4C6B-9072-9AE1ACCACF3E ; Apple TV 4K: xcrun simctl list devices | grep "Apple TV 4K"
DEV=BE69F376-A952-4C6B-9072-9AE1ACCACF3E
xcrun simctl boot $DEV; xcrun simctl bootstatus $DEV -b
xcrun simctl install $DEV apple/build/dd/Build/Products/Debug-iphonesimulator/Broadwave.app
# Pre-select a server (skip the Connect screen): FoundServer JSON as hex data
ID=$(curl -s 127.0.0.1:18477/api/v1/server | python3 -c "import sys,json;print(json.load(sys.stdin)['id'])")
HEX=$(python3 -c "import json,binascii;print(binascii.hexlify(json.dumps({'id':'$ID','name':'Dev','url':'http://192.168.1.127:18477'}).encode()).decode())")
xcrun simctl spawn $DEV defaults write com.wolfeup.broadwave server -data $HEX
xcrun simctl launch $DEV com.wolfeup.broadwave -BroadwaveWatch 1   # debug builds: auto-play channel id 1
```

tvOS products are in `Debug-appletvsimulator/BroadwaveTV.app`. Use the Mac's LAN IP (not 127.0.0.1) in the server URL so the same value works on devices. Deep links: `broadwave://watch/<id>`, `broadwave://guide|sports|recordings`, `broadwave://connect?url=<encoded>` (`simctl openurl` shows a confirmation alert you can't dismiss; prefer `-BroadwaveWatch`).

## Screenshots (the Read tool is picky)

Write screenshots INTO the workspace, downscale, and wait a few seconds before reading:

```bash
xcrun simctl io $DEV screenshot --type=jpeg "docs/screenshots/x-big.jpg"
sips -Z 1400 docs/screenshots/x-big.jpg --out docs/screenshots/x.jpg && rm docs/screenshots/x-big.jpg
```

Reading files just written to /tmp often fails with "File not found"; tvOS 4K PNGs fail too. Read after a short wait.

## Gotchas already hit

- tvOS has a system `.card` ButtonStyle; ours is `cardButton()` (system card on tvOS, press style on iOS). Don't name custom styles `CardButtonStyle` or nested types `Body` inside a `ButtonStyle`.
- `scrollContentBackground`, `presentationDetents`-style APIs may be unavailable on tvOS: guard with `#if os(iOS)`.
- `.glassProminent` with a white tint makes labels invisible; the app tint is the accent token.
- Local network: Info.plist has `NSLocalNetworkUsageDescription`, `NSBonjourServices`, ATS `NSAllowsLocalNetworking` + `NSAllowsArbitraryLoads` (self-hosted http). Revisit ATS before App Store.
- `AVPlayerItem.currentDate()` and `seek(to: Date)` use the server's PDT; that's what the SyncEngine relies on.
